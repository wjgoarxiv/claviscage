# Security

Please do not report security problems in public issues.

Send them to **woojingo.contact@gmail.com** with "ClavisCage security" in the subject. Describe what
you saw and how to reproduce it in the public web app (https://claviscage.app) or the engine in
this repository. Do not attach private structures or trajectories.

The web app runs entirely in your browser: structure files are read locally and are not uploaded to
a server. Reports about that boundary are especially welcome.
