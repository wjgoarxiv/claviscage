# Changelog

User-visible changes to the ClavisCage web app and to this documentation. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The analysis engine is in this
repository; the web app itself is not (see `NOTICE.md`).

## 0.3.18 — analysis engine (2026-11-10)

Engine `clavis-wasm` / `clavis_engine` 0.3.18. It includes the triclinic `.gro` fix that was first
cut as 0.3.17 and never released.

### Added
- Method registry: `list_methods` and `describe_method` (WebAssembly and Python) describe every
  published method with its citation, DOI, parameters with ranges, series, per-water values, how it
  can be shown, fixtures, open spec details and a verification level T0–T3. One generic
  `run_method` call runs any series method by id and parameters (CHILL+, F3/F4, averaged
  Steinhardt, MCG, tetrahedral order); errors carry a code such as `unknown_method`,
  `param_out_of_range` or `missing_input`. Cage detectors keep their own entry points.
- Locally averaged Steinhardt q4/q6 (Lechner & Dellago, J. Chem. Phys. 129, 114707, 2008). Per-water
  values match freud's `Steinhardt(average=True)` within its float32 precision on sI, sII,
  CH4-filled sI and a disordered 4,500-water frame.
- MCG-3 largest guest cluster (Barnes, Beckham, Wu & Sum, J. Chem. Phys. 140, 164506, 2014) with the
  paper's parameters (9 Å, 6 Å, 45°, Nw 5, Nc 3). Fully occupied sI and sII CH4 crystals form one
  cluster of 64 and 192 guests. A frame without guests reports a missing input.
- Tetrahedral order q (Errington & Debenedetti, Nature 409, 318, 2001) with S_g and S_k (Chau &
  Hardwick, Mol. Phys. 93, 511, 1998). Frame means match GROMACS 2026.2 `gmx order -Sg -Sk` within
  2×10⁻⁶ on a liquid frame, sII, hexagonal ice and the triclinic sH crystal (level T2). The
  neighbour search compares every pair of waters, so a frame is limited to 20,000 waters for now.
- The Python bindings accept the analysis kinds `steinhardt` and `mcg`.
- Every per-frame method reports a missing input when a frame has no waters with two hydrogens, and
  an error when a coordinate is not a finite number, instead of returning zeros.
- Benchmark: every method runs on GenIce2 sI, sII, sH, Ih and Ic crystals and is compared with the
  cage counts and phases known by construction. Results are in `benchmarks/results.json`
  (`cargo test --release --test benchmark_table`); see `docs/validation/benchmarks.md`. GRADE does
  not reach the exact counts on these periodic crystals because the original program tests ring
  planarity without the minimum image; this is listed as a known mismatch.
- Guest-containing reference crystals (`tests/fixtures/guests/`, GenIce2 sI and sII with CH4 in
  every cage) and reference values regenerated by `scripts/make_detector_fixtures.py`.
- Method notes for the new methods and the registry in `docs/methods/`.

### Fixed
- Triclinic `.gro` boxes keep their tilt: the parser returns all nine box values (`box_vectors`),
  and the Python binding and `clavis-cli` use the full cell. TRACE and HTR now find 48/32/16
  cages on a GenIce2 sH 2×2×2 crystal (fixture `tests/fixtures/crystals/222_SH.gro`).
- GRADE is a step-by-step port of GRADE v1.00 (ring search, planarity test, cup finding, cage
  assembly and filled-cage centres) and returns the same cage counts as the reference program on the
  4,500-water production frame and on five GenIce2 sI/sII crystals.

### Changed

- `NOTICE` credits the sources of the new reference values (freud, GROMACS) and the GenIce2
  fixtures.
- `CITATION.cff` is at 0.3.18.

## 2026-11-03 — public documentation repository

### Added
- This repository: method notes, a validation summary, the `.claviscage.zip` bundle schema,
  citation metadata, issue templates, a cover loop and app screenshots.

### Current app (https://claviscage.app)
- Free, no account, runs in the browser. TRACE, HTR, GRADE, CHILL+, F3/F4 and guest occupancy on
  GRO, PDB/mmCIF, GROMACS (GRO + XTC/TRR/TPR) and LAMMPS (data + dump) inputs.
- Light and dark themes in a computational-brutalist style; the 3D scene follows the theme.
- Path-traced PNG export renders the number of samples you choose.
- MP4 export and the 3D scene work offline: the ffmpeg.wasm core and the scene's environment map
  are served by the site itself, with no CDN.
- Large `.gro` trajectories (100 MB and up) stream frame by frame.
