# Cover assets

The README cover is an eight-second loop of a real sII hydrate crystal. The cell, its hydrogen bonds
and the highlighted 5¹² cage come from the ClavisCage engine run on a GenIce2 sII 2×2×2 crystal
(1,088 waters, 192 cages); three.js draws them frame by frame. It is artwork, not a figure for citation.

- **Motion**: the cage turns once per loop, a scan line sweeps the cell twice, and once per loop the
  cage lights, fills and lifts out before settling back. The loop is seamless.
- **Files**: `cover-dark.webp` (1.96 MiB) and `cover-light.webp` (1.88 MiB), animated WebP,
  1000 × 500, 20 fps. `poster-*.png` is the first frame, shown when reduced motion is requested.
- **Type**: Pretendard and MesloLGS NF, rendered into the frames.
- **Checks**: each loop passed size, seam, legibility, title-contrast and photosensitive-flash audits.

File hashes, wording and fonts are recorded in [`cover-source.json`](cover-source.json). The cover
falls under the repository's CC BY 4.0 licence.
