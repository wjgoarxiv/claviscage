# F3 / F4 order parameters

Local water-order parameters, not cage detectors. Interpret them with the temperature, water model,
cutoff and sampling in mind. Full page: https://docs.claviscage.app/analysis/f3f4

## F3 (three-body oxygen order)

For each central oxygen, every unordered pair of oxygen neighbours inside the cutoff contributes

    (cos θ · |cos θ| + 1/9)²

`f3_per_atom` averages the triplets centred on each water. `f3_overall` averages **all contributing
triplets**, not the per-water values. Lower values mean more tetrahedral order.

## F4 (torsional order)

For each neighbouring water pair, take the hydrogen pair with the largest periodic H–H separation,
measure the `H–O···O–H` dihedral φ, and average

    F4 = ⟨cos 3φ⟩

`f4_overall` averages each unique water pair once and lies in [−1, 1].

## Geometry

Default O–O cutoff 0.35 nm. Orthorhombic and triclinic cells use minimum-image distances.

## Reference

The engine registry cites Rodger et al., *Fluid Phase Equilib.* 116 (1996) 326, and Moon et al.,
*Faraday Discuss.* 136 (2007) 367 (https://doi.org/10.1039/b618194p). The F4 pair rule follows the
CalF4 program distributed with GRADE. Verification level T1: the published definitions, checked
on sI and sH water clusters against F4SPC values (see [`method-registry.md`](method-registry.md)).
